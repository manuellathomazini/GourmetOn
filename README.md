# 🍝 GourmetOn

Um projeto acadêmico de Landing Page para a apresentação de um Aplicativo de Delivery

## 🛠️ Tecnologias utilizadas

- [React](https://react.dev/) — biblioteca para construção da interface
- [Vite](https://vitejs.dev/) — servidor de desenvolvimento e build
- [Tailwind CSS](https://tailwindcss.com/) — estilização utilitária
- [MUI](https://mui.com) e [Lucide](https://lucide.dev )- ícones
- `fetch()` — fazer requisições HTTP de forma assíncrona nos navegadores

## 🚀 Como rodar localmente

Pré-requisitos: [Node.js](https://nodejs.org/) instalado (recomendado LTS).

```bash
# 1. Clone o repositório
git clone https://github.com/manuellathomazini/GourmetOn.git

# 2. Acesse a pasta do projeto
cd GourmetOn

# 3. Instale as dependências
npm install
npm install @mui/icons-material @mui/material @emotion/styled @emotion/react

# 4. Rode o projeto em modo de desenvolvimento
npm run dev
```

A aplicação abrirá por padrão em `http://localhost:5173`.
